# Resume folder

Drop your resume PDF(s) here. The website automatically loads the **most recently
modified** `.pdf` in this folder and shows it under the `resume.pdf` entry in the sidebar.

- Filenames can be anything ending in `.pdf` (e.g. `Deepankar-Yadav-Resume.pdf`).
- You can keep older versions here too — only the newest one is displayed.
- During `npm run dev` the site hot-reloads the moment you add/replace a PDF.
- For the deployed site, rebuild (`npm run build`) and redeploy to pick up a new PDF.

This README is ignored (only `.pdf` files are picked up).
